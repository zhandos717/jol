# 0009. PostGIS пока не нужен

**Контекст.** Геозапросов много, но они разные: «ближайшие водители» и «спрос по зонам» — горячие, по данным, живущим секунды; координаты заказов только хранятся.

**Решение.** Горячие геозапросы считаются в памяти (`fleet`, `pricing`) по сетке около 1.5 × 1.5 км и формуле гаверсинуса. В БД точки хранятся как пары `DOUBLE PRECISION`.

**Когда пересмотреть.**
- Зоны произвольной формы: аэропорт с отдельным тарифом, границы зоны обслуживания.
- Поиск рейсов попутчиков при тысячах рейсов в день (`ST_DWithin` с GiST-индексом).
- Аналитика и тепловые карты по истории поездок.

**Последствия.** Переход не ломает модель: образ `postgis/postgis`, колонка `geography(Point)`, заполненная из существующих lat/lon одной миграцией.

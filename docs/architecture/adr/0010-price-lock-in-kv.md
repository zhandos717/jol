# 0010. Фиксация цены через NATS KV с TTL

**Контекст.** Пассажир видит цену, думает минуту и нажимает «Заказать». Если за это время коэффициент спроса вырос, списать больше показанного — плохой опыт и юридический риск.

**Решение.** `pricing` сохраняет при показе цены `quoteId → {surge, from}` в бакете KV `quotes` с TTL 3 минуты. `dispatch` передаёт `quoteId` в `pricing.price`. Зафиксированный коэффициент применяется, только если точка подачи не сдвинулась больше чем на 300 м.

**Альтернативы.** Хранить котировки в памяти `pricing` — ломается при нескольких репликах. В PostgreSQL — лишняя запись на каждый просмотр цены, а данные нужны 3 минуты.

**Последствия.** `pricing` остаётся без собственной БД и масштабируется горизонтально. Истёкшие котировки удаляет NATS.

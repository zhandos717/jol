# 0008. Свой OSRM, внешний геокодер

**Контекст.** Каждый расчёт цены требует маршрута. Публичный OSRM ограничен примерно 1 запросом в секунду и запрещает коммерческую нагрузку.

**Решение.** OSRM в docker-compose с картой Казахстана с Geofabrik (224 МБ, подготовка около 2 минут, ~600 МБ памяти, алгоритм MLD). Браузер получает маршруты через шлюз (`/osrm/...`). Поиск адресов пока остаётся на публичном Nominatim.

**Альтернативы.** 2GIS или Яндекс API — точнее адреса и есть пробки, но нужен договор и ключ. Свой Nominatim по Казахстану — 8+ ГБ памяти и около 50 ГБ диска.

**Последствия.** ~800 расчётов цены в секунду на одном ядре. Нет учёта пробок: время в пути и цена занижены в часы пик. Геокодер — главный внешний риск перед запуском.
